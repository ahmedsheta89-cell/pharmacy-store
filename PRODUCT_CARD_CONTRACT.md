# Product card contract v1

The existing product ID is stable across import/export and POS integration.
Legacy commercial fields are `id`, `name`, `nameEn`, `category`, `price`, `unit`,
`imageUrl` (image reference), `description`, `oldPrice`, `badge`.

Reviewed content fields: `dosage_information`, `usage_instructions`, `warnings`,
`content_source`, `content_reviewer`, `content_reviewed_at` (ISO date),
`content_version`, `content_review_status` (`unreviewed` or `reviewed`).
Clinical fields start empty. Seeded descriptions are unreviewed, not clinical evidence.
A change to clinical text resets the review state. Reviewed content requires all
provenance fields. Nothing is generated by AI.

Publication: `prescription_status` is `unknown`, `non_prescription`, `prescription`,
or `not_medicine`. `advertising_status` is `unreviewed`, `approved`, or `blocked`.
Only a pharmacist's explicit content review, explicit advertising approval, and a
non-prescription/non-medicine classification can derive `public_visible: true`.
Classification alone never implies advertising permission. The pharmacist must
verify the local rules and source information; the app does not infer legal status.
Unreviewed/prescription products remain admin-only. Public queries read only visible
records, and backend checkout enforces the same gate.

`stock_quantity` is an optional nonnegative integer, not a live POS integration.
Zero stock and requested quantities above the recorded amount cannot be ordered.
Concurrent COD requests are confirmed by the pharmacy before fulfillment; this is not
an automatic inventory-reservation system. Import/export must never infer clinical
approval or advertising eligibility from column names or item categories.

## XLSX gateway

`CatalogExcel` accepts XLSX value-only workbooks up to 8 MB compressed / 40 MB
uncompressed, 1000 product rows and 150 columns per sheet. It rejects formula cells,
ZIP64 and malformed ZIP directories. The user selects the sheet and reviews suggested
column mappings. Ambiguous headers remain unmapped. Required name/price, duplicate
IDs, existing IDs, precise prices, integer stock, and HTTPS image references are checked
before any write. Existing IDs require explicit update permission. A final review
checkbox enables commit. Each chunk (200 rows) is atomic; a failure reports the number
saved, and IDs make retries idempotent. No rows are deleted by import.

All imports become private unreviewed drafts, including updates to previously published
items. File/sheet provenance is `import_source`; clinical provenance is not invented.
The XLSX export uses stable field names for POS compatibility, Arabic instructions,
RTL sheets, frozen headers, filters, numeric prices, wrapped text and typed string cells.
Formula-like text stays text. ExcelJS is loaded only when needed; no workbook contents
are sent to an external analysis service.
